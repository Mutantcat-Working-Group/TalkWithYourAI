# Support

Looking for help with TalkWithYourAI? Here's where to go:

## Bug Reports

If you've found a bug, please [open an issue](https://github.com/Mutantcat-Working-Group/TalkWithYourAI/issues/new?template=bug_report.yml) with steps to reproduce.

## Feature Requests

Have an idea? [Open a feature request](https://github.com/Mutantcat-Working-Group/TalkWithYourAI/issues/new?template=feature_request.yml).

## Security

Found a security vulnerability? Please report it privately via [GitHub Security Advisories](https://github.com/Mutantcat-Working-Group/TalkWithYourAI/security/advisories/new). See [SECURITY.md](SECURITY.md) for details.
